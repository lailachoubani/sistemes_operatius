↑ Tornar a l'índex

1.1 Estructura física d'un disc

Gestor d’arrencada: és un programa que s’executa en encendre l’ordinador, abans que es carregui el sistema operatiu. Decideix quin sistema carregar i sovint mostra un menú per triar-ne un. A Ubuntu és GRUB.

Disc mecànic (HDD): guarda la informació en uns plats magnètics que giren, i un capçal que llegeix i escriu sobre ells. Té parts mòbils, així que és més lent i més fràgil als cops, però és més barat per gigabyte.

Disc sòlid (SSD): guarda la informació en memòria flaix, sense cap part mòbil. És més ràpid i més resistent als cops, però és més car per gigabyte.

↑ Tornar a l'índex

1.2 Estructura lògica d'un disc

Format de particions del disc: és la manera com el disc es divideix en particions. Hi ha dos formats: MBR i GPT.

MBR (Master Boot Record): és el format antic, que s’usa amb BIOS. Permet fins a 4 particions primàries i només admet discs de fins a 2 TB.

GPT (GUID Partition Table): és el format actual, que s’usa amb UEFI. No té el límit de quatre particions i admet discs de més de 2 TB. Guarda una còpia de la taula de particions i fa comprovacions d’integritat, així que és més segur.

↑ Tornar a l'índex

1.3 Estructura de la informació

Partició

Definició: una part del disc que el sistema veu com una unitat independent, amb la seva pròpia mida i el seu propi sistema de fitxers.

Volum

Definició: abstracció que es posa per sobre de les particions. Pot combinar diverses particions o discs en una sola unitat i es pot redimensionar sense reparticionar el disc.

Diferència: una partició és una divisió física del disc, mentre que un volum és una capa lògica que la gestiona.

1.6 Tipus de formateig

Pas 0. Preparar-ho tot

0.1 Instal·lar photorec

sudo apt install testdisk
which photorec

Resultat esperat: /usr/bin/photorec

0.2 Crear la carpeta de la pràctica

mkdir -p ~/practica
cd ~/practica
pwd

Resultat esperat: /home/alumnat/practica

0.3 Posar-hi els fitxers de prova

echo "El meu secret és que m'encanta la pizza amb pinya" > notes.txt
ls -l

Part 1. Crear el disc virtual

1.1 Crear el fitxer

dd if=/dev/zero of=disc.img bs=1M count=200 status=progress

1.2 Comprovar que existeix

ls -lh disc.img

Part 2. Formatar el disc i desar-hi fitxers

2.1 Donar format al disc

mkfs.ext4 disc.img

2.2 Muntar el disc

sudo mkdir -p /mnt/prova
sudo mount -o loop disc.img /mnt/prova

2.3 Copiar-hi els fitxers

sudo cp foto.jpg apunts.pdf notes.txt /mnt/prova/
ls -l /mnt/prova

2.4 Desar els hashes dels originals

sha256sum foto.jpg apunts.pdf notes.txt > originals.sha
cat originals.sha

2.5 Desmuntar el disc

sudo umount /mnt/prova

Part 3. Formateig d'alt nivell

3.1 Tornar a formatar (sense esborrar el contingut)

mkfs.ext4 -E nodiscard disc.img

Escriu y quan mkfs demani confirmació.

3.2 Comprovar què hi ha al disc

sudo mount -o loop disc.img /mnt/prova
ls -l /mnt/prova
sudo umount /mnt/prova

Resultat esperat: només lost+found.

Part 4. Recuperar els fitxers

4.1 Executar photorec

photorec /d recup /cmd disc.img
options,fileopt,everything,enable,search

4.2 Veure què ha trobat

ls recup.1

4.3 Comprovar que són idèntics

sha256sum recup.1/*
cat originals.sha

4.4 Buscar el text de notes.txt

strings -e S disc.img | grep pizza

Part 5. Esborrat de baix nivell

5.1 Omplir el disc de zeros

dd if=/dev/zero of=disc.img bs=1M count=200 conv=notrunc status=progress

5.2 Tornar a intentar recuperar fitxers

photorec /d recup_zeros /cmd disc.img
options,fileopt,everything,enable,search
ls recup_zeros.1

5.3 Buscar el text un altre cop

strings -e S disc.img | grep pizza

Neteja

cd ~/practica
rm -rf disc.img recup.1 recup_zeros.1 originals.sha
ls -l

4. Gestió d'usuari i grup i permisos

Resum · Conceptes

Usuari: identitat del sistema, amb nom, UID, carpeta personal i shell. Els fitxers i els processos sempre pertanyen a un usuari.

UID: número de l'usuari. 0 és root, de 1 a 999 són usuaris del sistema (serveis), i a partir de 1000 són persones.

Grup: conjunt d'usuaris amb nom i número (GID). Serveix per donar permisos a diverses persones alhora.

Grup principal: el grup dels fitxers que crea l'usuari. Cada usuari en té un i només un. Ubuntu crea per a cada usuari un grup personal amb el mateix nom.

Grups secundaris: altres grups als quals pertany l'usuari. En pot tenir tants com calgui.

Fitxers importants: /etc/passwd (usuaris), /etc/shadow (contrasenyes xifrades, només root), /etc/group (grups), /etc/skel (carpeta model de cada usuari nou) i /home (carpetes personals).

Ordres d'Ubuntu: useradd, userdel i groupadd no pregunten res i no creen carpeta personal si no els ho dius. adduser, deluser i addgroup són interactives i ho fan tot sols.

Gairebé totes les ordres d'usuaris i grups s'executen amb sudo.

Abans de començar

Fes una instantània de la màquina virtual. Si t'equivoques amb un usuari, la pots recuperar i tornar a començar.

sudo -v

Nivell 1 · Crear usuaris

1.1 Crear la Núria amb useradd (sense opcions)

sudo useradd nuria

3.1 Crear grups

Nivell 4 · Afegir i treure usuaris dels grups

4.1 Afegir sense perdre grups

sudo usermod -aG programadors nuria
groups nuria
sudo gpasswd -a pau artistes
sudo adduser marc testers
sudo adduser laia becaris
sudo gpasswd -a laia artistes

4.2 L'error del -G sense la a

sudo usermod -G testers nuria
groups nuria

Aquí la Núria ha perdut el grup programadors. Torna-la a afegir amb -aG.

sudo usermod -aG programadors nuria
groups nuria

4.3 Treure un usuari d'un grup

sudo gpasswd -d laia artistes

També es pot fer amb sudo deluser laia artistes.

4.4 Comprovació

5.1 Abans del canvi

sudo usermod -g programadors pau

Nivell 6 · Bloquejar i desbloquejar un compte

6.1 Bloquejar Marc

sudo passwd -S marc
sudo passwd -l marc
sudo passwd -S marc
sudo grep marc /etc/shadow

La P vol dir contrasenya vàlida, i la L vol dir bloquejat. Davant de la contrasenya xifrada apareix un !.

6.2 Comprovar que no pot entrar

su - marc

6.3 Desbloquejar

sudo passwd -u marc
sudo passwd -S marc
su - marc
exit

Captura 7 (pendent): el ! a /etc/shadow, l'error Authentication failure i l'estat P després de desbloquejar.

No bloquegis mai el teu propi usuari. Si ho fas, no podràs fer servir sudo per desbloquejar-te.

Nivell 7 · Canviar el nom d'un usuari

La Núria no pot tenir cap sessió oberta. Si encara hi ha un terminal amb su - nuria, escriu-hi exit.

7.1 Canviar el nom d'usuari

sudo usermod -l nvidal nuria
id nvidal
grep nvidal /etc/passwd

El nom ha canviat, però el grup personal encara es diu nuria i la carpeta continua sent /home/nuria.

7.2 Canviar el grup personal i la carpeta

sudo groupmod -n nvidal nuria
sudo usermod -d /home/nvidal -m nvidal

7.3 Comprovacions

id nvidal
ls -l /home
ls -l /home/nvidal
su - nvidal
whoami
exit

Captura 8 (pendent): el primer id nvidal i el del pas 7.3.

Nivell 8 · Esborrar usuaris i grups

8.1 Esborrar Laia sense -r

ls -l /home
sudo userdel laia
ls -l /home

La carpeta continua allà, però el propietari surt amb un número. És l'UID d'un usuari que ja no existeix.

8.2 Esborrar la carpeta orfe

sudo rm -r /home/laia

Llegeix l'ordre dues vegades abans de prémer Enter.

8.3 Esborrar el grup becaris

sudo delgroup becaris
getent group becaris

8.4 Estat final de PixelForge

getent passwd nvidal pau marc
getent group programadors artistes testers
