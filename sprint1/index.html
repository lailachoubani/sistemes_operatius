1. Instal·lació del sistema operatiu

He fet aquesta instal·lació dins d'una màquina virtual amb VirtualBox, amb Ubuntu 26.04 LTS. Un cop arrencat el suport d'instal·lació, he seguit l'assistent i he triat les opcions de particionat abans de continuar. Aquest pas és irreversible, així que revisa bé el disc de destinació.

  1. Crear la màquina virtual. Nom ubudesk26.04, carpeta /home/alumnat/VirtualBox VMs i imatge ISO (baixada a la carpeta Baixades) ubuntu-26.04.1-desktop-amd64.iso.
  2. Creació del disc dur virtual.
    Disc de 30 GB.
  3. Configurar el particionat del disc.
    Particions: / (10 GB), /home (15 GB) i /boot (2 GB).
  4. /home (15 GB): partició on es guarden els fitxers personals de l'usuari, separada del sistema.
  5. /boot (2 GB): partició on es guarden els fitxers d'arrencada, com el nucli i GRUB.
  6. / (10 GB): partició principal on s'instal·la el sistema operatiu i les aplicacions.

3. Gestors arrencada

Un gestor d'arrencada és el programa que s'executa en encendre l'ordinador i permet triar quin sistema operatiu carregar. A Ubuntu és GRUB.

  1. Primer vaig entrar a /boot i vaig esborrar la carpeta grub/ amb sudo rm -r grub/.

  2. En reiniciar, la màquina no va arrencar i va mostrar l'error "normal.mod not found", amb el mode grub rescue>

  3. Vaig intentar arrencar amb Super Grub2 Disk, connectant la seva ISO a la unitat òptica de VirtualBox. Des del seu menú no vaig poder arrencar el sistema.

  4. Per tant vaig fer ús del Boot Repair. Amb aquesta eina es va reparar l'arrencada.

  5. Per usar Boot Repair vaig connectar la seva ISO a la configuració de VirtualBox.

  6. Un cop reparat, la màquina va arrencar fins a l'escriptori d'Ubuntu, i la carpeta grub torna a estar present a /boot.

5.Comandes generals

Les comandes generals són les ordres bàsiques de la terminal per navegar pel sistema i gestionar fitxers. Amb cd entro a un directori, amb ls veig el que hi ha, i amb cat o nano puc veure o editar un fitxer. Per instal·lar aplicacions faig servir apt, amb sudo quan cal permisos d’administrador.
